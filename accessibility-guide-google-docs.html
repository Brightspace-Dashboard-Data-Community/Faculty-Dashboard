Google Docs

Shared docs and published links should use headings, styles, and alt text similar to Word.

Structure

  • Apply Title and Heading 1–3 from the styles menu; avoid visual-only formatting.
  • Use the list buttons for bullets and numbering.
  • For tables, include header rows and keep layouts simple.

Images & color

  • Right-click an image → Alt text and describe informative graphics.
  • Check contrast and avoid color as the only cue.

Verify

  • Use Tools → Accessibility to run checks and follow prompts to fix issues before sharing or embedding.
