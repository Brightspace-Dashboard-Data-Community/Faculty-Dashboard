What this tool creates

In the selected course, this tool creates (or reuses) a discussion forum named Student Private Conversations, a matching group category, one one-person group per student, one discussion topic per student, and group restrictions so each topic is visible only to that student (and instructors).

Re-running the tool skips students who already have a matching topic and group, so you can safely add boards for students who joined later.
