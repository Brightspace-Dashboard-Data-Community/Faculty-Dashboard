D2L Webpages & HTML content

Structure and test HTML pages, topics, and widgets in Brightspace so screen reader and keyboard users can use them effectively.

Structure & semantics

  • Use a single logical Heading 1 per page or major topic, then Heading 2 and Heading 3 in order—do not skip levels for visual styling.
  • Use real heading styles in the HTML editor instead of bold or large font alone.
  • Use bulleted or numbered lists for groups of related items; avoid fake lists made of line breaks.
  • Use built-in table tools for data tables; include header rows and keep layout simple.

Images, links, and media

  • Add concise alt text for meaningful images; use empty alt (decorative) only when an image adds no information.
  • Make link text descriptive (“Syllabus PDF”) instead of generic (“click here”).
  • For video or audio, provide captions; add transcripts or descriptions when narration alone does not convey visual information.

Use D2L tools

  • Run the Accessibility Checker in the HTML editor before publishing.
  • Review YuJa Panorama feedback on the page or uploaded files and remediate issues (or provide an equivalent accessible format) where suggested.
