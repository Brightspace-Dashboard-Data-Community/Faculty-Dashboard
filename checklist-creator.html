How this tool works

Creates a real Checklist in the selected course (name, categories, and items) through the Brightspace API. Optionally adds a link topic in a content module that opens the checklist for students.

Native “Add Existing → Checklist” topics are not fully supported by the Content API, so module placement uses the Brightspace checklist page (checklist.d2l). You can also attach any existing checklist to a module without recreating it.
