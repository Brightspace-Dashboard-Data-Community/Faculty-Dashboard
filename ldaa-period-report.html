Track Last Date of Academic Activity for a selected week or date range. Run the whole class or one student, then export CSV, Excel, or a branded PDF.

Build a report

Choose a course, a calendar range, and whether to include the entire class or one student. The snapshot shows the latest submission date in that window for assignments, quizzes, and discussion boards, plus last course login when it falls in the period. Detailed results list every matching submission date. Course login alone does not count as LDAA.
