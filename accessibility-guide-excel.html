Microsoft Excel

Tables, sheet names, and cell relationships should be clear for keyboard navigation and screen readers.

Tables & structure

  • Use Insert → Table for data grids; include header rows (and header columns when needed).
  • Give each sheet a short, meaningful name; avoid blank default sheet names only.
  • Keep one logical table per region when possible; avoid split titles or blank spacer rows inside a table.
  • Do not merge cells in ways that break header association for complex tables.

Content & visuals

  • Add alt text to charts and embedded images.
  • Include text explanations for important trends shown only in charts.
  • Avoid color-only meaning; add data labels or patterns and use sufficient contrast.

Verify

  • Run Review → Check Accessibility before distributing the workbook or uploading to D2L.
