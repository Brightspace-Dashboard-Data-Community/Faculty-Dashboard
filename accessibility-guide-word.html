Microsoft Word

Prepare syllabi, handouts, and instructions so they stay accessible when students open them in Word or download them from D2L.

Document structure

  • Apply built-in Heading 1–3 styles instead of manual font size and bold.
  • Use Styles for emphasis; avoid all-caps blocks for long passages.
  • Use Word’s list tools for bullets and numbering.
  • For tables, designate a header row and avoid merged cells for complex data when possible.

Visuals & color

  • Right-click images → Edit Alt Text and describe informative graphics.
  • Do not rely on color alone to convey meaning; add text labels or patterns.
  • Check contrast between text and background (aim for roughly 4.5:1 for normal text).

Verify before sharing

  • Run Review → Check Accessibility and fix issues in the Inspection Results pane.
  • Export or save to PDF only after Word accessibility issues are resolved (then check the PDF separately if you distribute PDFs).
