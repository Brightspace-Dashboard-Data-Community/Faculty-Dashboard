Course Package Deployer

Build a course shell from one screen: materials, gradebook, assignments, quiz shells, discussions, content, and a welcome announcement.

What this deploys

Gradebook: calculation system, null-grade handling, default scheme, categories (weights / drop highest-lowest / even distribution), and grade items.

Assignments: submission folders with points, due dates, instructions, submission type, and optional linked grade items.

Quizzes: empty quiz shells with settings (attempts, time limit, shuffle, dates), optional Quizzes-tool categories, and optional linked grade items. Questions are added later in Brightspace (API cannot create questions).

Discussions: forums + topics (CSV supported), optional private per-student boards.

Content: weekly/module shells (titles + optional dates); topics added later by instructors.

Also: optional course banner, syllabus + office hours upload, welcome announcement, and a reminder to update your Single Profile Widget.

1. Course & materials

Current () and upcoming () teaching courses, plus sandboxes.

Sets the course image (My Courses tile / Pulse). JPEG, PNG, or GIF under 2000 KB. This does not turn on the homepage banner — after deploy, open Course Admin → Course Offering Information and check Display the image in a banner on the course homepage.

After deploy — Single Profile Widget

This tool cannot configure the Faculty / Single Profile Widget. After deploy you will be reminded to open the course homepage, choose Configure this widget, update your info, and upload a photo.

Uploaded into a Course Information content module.

2. Gradebook setup
Calculation system

Points: final grade from total points earned. Weighted: categories/items contribute by percent. Formula: set system here; finish the formula in Brightspace Grades setup.

Brightspace “Null grade is treated as zero” setting.

Loaded from the selected course when available.

                        4. Quizzes
                        

                            
Creates Brightspace quiz shells (settings + optional grade link). Questions cannot be added via API — after deploy, open Quizzes in the course to import or build questions. When “Create & link grade item” is checked, deploy reuses a matching gradebook item or creates a new one (same prompt pattern as assignments).
