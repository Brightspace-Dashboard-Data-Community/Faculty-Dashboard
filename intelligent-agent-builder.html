What are Intelligent Agents?

Intelligent Agents are automated email systems that send messages to students when specific criteria are met. They help you stay connected with your students by automatically sending personalized emails based on their activity, grades, or engagement in your course. Use the steps below: choose a template, then set it up in your course.

Key Benefits
  • Automate student communications based on course activity
  • Send personalized emails using replace strings
  • Improve student engagement and retention
  • Save time by automating routine communications
  • Track student activity and respond proactively

How to Create an Intelligent Agent

1
Access Intelligent Agents
  1. Navigate to your course in D2L
  2. Select Edit Course from the course navigation or from Course Tools dropdown menu
  3. Select Intelligent Agents (under "Communication" in Edit Course if viewing by category)
2
Create a New Agent
  1. On the Agent List page, click New Agent
  2. Enter an Agent Name (required) - e.g., "Welcome Message" or "Low Grade Alert"
  3. Enter an optional Description to help you remember what this agent does
  4. Check Agent is Enabled if you want it active immediately
3
Configure Scheduling

Select how often the agent should check for criteria:

  • One-Time Run- Only runs once
  • Hourly - Checks once per hour
  • Daily - Checks once per day at a specified time
  • Weekly - Checks once per week on a specific day
  • Monthly - Checks once per month
  • Annually - Checks once per year
  • No Schedule - Only runs when you click "Run Now" or for Testing Purposes

Note: Intelligent Agents are automatically disabled when a course becomes inactive.

4
Set Criteria

Define what conditions trigger the agent:

  • Role in Classlist: Choose "All users" or "Users with specific roles" (e.g., only Students)
  • Login Activity: Trigger when users haven't logged in within a certain timeframe
  • Course Activity: Trigger when users haven't accessed the course within a timeframe
  • Release Conditions: Create conditions based on:
    • Grade received on an assignment
    • Content viewed or not viewed
    • Quiz completed or not completed
    • Discussion posts made
    • And many more options

Tip: You can leave criteria empty if you just want to send a general email to all students.

5
Configure Actions
  • Choose when to take action:
    • First time criteria are met - Send email once per student
    • Every time criteria are met - Send email each time conditions are satisfied
  • Check Send an email when the criteria are satisfied
6
Compose Email
  • Enter {InitiatingUser} as the "To" field to send the email to the student who meets the criteria
  • Enter an Email Subject (required)
  • Write your Message in the text area
  • Use Replace Strings to personalize messages (see Replace Strings tab)
  • Optionally attach files from your computer or course files

Example Subject: "Welcome to {OrgUnitName}!"

Example Message: "Dear {InitiatingUserFirstName}, welcome to {OrgUnitName}. We're excited to have you in this course!"

7
Save and Test
  1. Click Save and Close
  2. Use Practice Run to see who would receive the email (no emails sent)
  3. If satisfied, use Run Now to execute the agent immediately

Help

How to create agents in Brightspace, course-wide email settings, and replace strings for personalized messages.

Email Settings & Configuration

Default Email Settings

By default, Intelligent Agent emails come from "System - No Reply" with a reply-to address of "system_noreply@brightspace.com".

Important: It's recommended to change this to an email address that is monitored by a person so students can reply to your messages.

1
Access Email Settings
  1. Go to the Agent List page in your course
  2. Click the Settings button (gear icon) at the top of the page
2
Configure Custom Email Settings
  1. Check the box for "Set custom values for this course"
  2. Enter the Name that should appear as the sender (e.g., "Professor Smith" or "Dr. Johnson")
  3. Enter the Reply-to Email Address where students should send replies (e.g., "professor.smith@example.edu")
  4. Click Save

Note: These settings apply to ALL Intelligent Agents in the course. You cannot set different email addresses for individual agents.

3
Edit an Existing Agent
  1. On the Agent List page, click the name of the agent you want to edit
  2. Make any changes to the agent configuration
  3. Click Save to update the agent
4
Test Your Agent

Practice Run: See who would receive the email without actually sending it

  1. Click the dropdown arrow next to the agent name
  2. Select Practice Run
  3. Click Run
  4. Review the list of students who would be contacted

Run Now: Execute the agent immediately

  1. Click the dropdown arrow next to the agent name
  2. Select Run Now
  3. Click Run in the confirmation dialog

Replace Strings Reference

Replace strings are special codes that automatically fill in personalized information when the email is sent. Use them in both the email subject and message body.

Replace String What It Generates
{InitiatingUser} The user who performs the action that meets the criteria (use in "To" field)
{OrgName} The name of your organization/institution
{OrgUnitCode} The course code (e.g., ENG-101-001)
{OrgUnitName} The full name of the course
{OrgUnitId} The unique ID number for the course
{InitiatingUserFirstName} The first name of the student receiving the email
{InitiatingUserLastName} The last name of the student receiving the email
{InitiatingUserUserName} The username of the student receiving the email
{InitiatingUserOrgDefinedId} The student ID number
{LoginPath} The web address/URL for logging into D2L
{LastCourseAccessDate} The date the student last accessed the course
{LastLoginDate} The date the student last logged into D2L
Example Email Using Replace Strings

Subject: Welcome to {OrgUnitName}!

Message:

Dear {InitiatingUserFirstName},

Welcome to {OrgUnitName}! I'm excited to have you in this course.

Your username is {InitiatingUserUserName} and your student ID is {InitiatingUserOrgDefinedId}.

Please log in to the course site at {LoginPath} to get started.

Best regards,
Professor Smith

When sent to John Doe:

Dear John,

Welcome to Introduction to Psychology! I'm excited to have you in this course.

Your username is jdoe123 and your student ID is 12345678.

Please log in to the course site at https://your-brightspace.example.edu to get started.

Best regards,
Professor Smith
