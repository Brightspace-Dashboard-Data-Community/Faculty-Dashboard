PDF documents

PDFs are widely used in courses; they need tags, reading order, and alt text like web pages.

Start from an accessible source

  • Whenever possible, author in Word or another structured editor, fix accessibility there, then export to PDF.
  • Scanned image-only PDFs are not accessible until you run OCR and add tags and reading order in Acrobat (or provide an equivalent accessible format).

In Adobe Acrobat Pro

  • Use Make Accessible or Autotag workflows as appropriate, then review the Tags tree.
  • Set document title and language in properties.
  • Verify reading order and fix tags (headings, lists, tables) where the structure is wrong.
  • Add alt text to figures via the tags or reading order tools.
  • Run Accessibility Check and address reported issues.

In D2L

  • Upload the cleaned PDF and open its YuJa Panorama Accessibility Report; use Guided Remediation, AutoPilot, or Structural Remediation as needed. Students can also download alternative formats from the report.
