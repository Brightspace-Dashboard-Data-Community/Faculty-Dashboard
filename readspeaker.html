How reading areas work

The Listen button’s readid parameter points to one or more HTML element IDs. On this page it is set to rs-read-area, so only content inside that element is read.

  • Use readid=section1,section2 for multiple IDs.
  • Or switch to readclass=my-class to target CSS classes instead.
  • Add class rs_skip on elements that should be visible but not spoken.
